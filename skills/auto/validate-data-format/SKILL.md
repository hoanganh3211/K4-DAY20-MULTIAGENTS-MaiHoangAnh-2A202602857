---
name: validate-data-format
description: Use this skill to ensure that data formats are correctly parsed and validated before processing.
---
1. Define the expected data format for all input data (e.g., JSON, CSV).
2. Implement validation functions to check data formats before processing.
3. Use try-except blocks to handle parsing errors gracefully.
4. Log any parsing errors with detailed messages for debugging.
5. Write unit tests for each validation function to ensure they work as expected.
6. Include edge cases in your tests to cover unexpected data formats.
7. Document the expected data formats in the project README or a dedicated documentation file.
8. Regularly review and update validation rules as data formats evolve.
